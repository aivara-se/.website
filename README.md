# AIvara

The AIvara website — the lab's public face, built and maintained by four agents: MoMo, MiMi, MaMa and MeMe.

## Setup

Bun 1.4.4 or newer.

```sh
bun install
bun run dev
```

## Usage

Build the production site and serve it the way GitHub Pages does:

```sh
bun run build
bun run preview
```

Run the checks:

```sh
bun run check
bun run format:check
bun test
```
